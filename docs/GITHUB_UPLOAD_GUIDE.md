# Repository and MATLAB run guide

This project is a private **synthetic demonstration**, not the original assessed group submission.

1. Download the repository as ZIP from GitHub's **Code** menu and extract it.
2. Open the extracted repository folder in MATLAB R2020a or newer.
3. Run `run_cycling_demo.m` from the MATLAB editor. The code reads `data/synthetic_ride.gpx` relative to the script.
4. Check the MATLAB Command Window for imported track points, total route distance and modelled energy.
5. Inspect the six generated `results/matlab_*.png` figures. The `synthetic_*.svg` images in `results/` are reference previews, not MATLAB outputs.
6. Verify team/university permissions before sharing original work, and keep original Strava GPX data private.
7. Only if you decide to publish, change the repository's visibility from Private to Public in GitHub settings, then share its URL in LinkedIn.

Do not upload the original ENGG100 assessment code, personal cycling tracks or project brief to this demonstration repository without permission.
