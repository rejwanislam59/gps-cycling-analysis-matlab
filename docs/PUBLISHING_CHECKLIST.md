# Publishing checklist

This repository is **private** while its owner reviews these items. This document is guidance, not a claim that any step is already complete.

- [ ] Run `run_cycling_demo.m` in MATLAB R2020a or later with `data/synthetic_ride.gpx`.
- [ ] Confirm that the six `matlab_*.png` graphs are generated in `results/` without MATLAB errors.
- [ ] Check the graphs, total distance and total modelled energy for sensible values.
- [ ] Confirm that all datasets are synthetic and no private GPS logs, exact activity times, home locations or teammate data are included.
- [ ] Confirm the original collaborative assessed code, screenshots and university teaching materials are not included without permission.
- [ ] Confirm course rules and group publishing permissions before posting any original assignment files or results.
- [ ] Keep the README's distinction between original group work and this separate AI-assisted demonstration.
- [ ] Check that the figure previews are labelled synthetic; never describe them as results from a MATLAB run.
- [ ] Review all Markdown links and ensure the repository remains private until all checks are complete.
- [ ] Only after approval and testing, optionally make it public and include the actual repository URL in LinkedIn.

Do not treat illustrative power estimates as direct sensor measurements or engineering design values.
