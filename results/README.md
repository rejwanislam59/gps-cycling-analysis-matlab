# Figure previews and MATLAB outputs

The six `matlab_*.png` figures in this folder were **uploaded after the project owner ran `run_cycling_demo.m` in MATLAB** using the fictitious track `../data/synthetic_ride.gpx`. The Command Window screenshot showed 660 points, UTM zone 53, 4.073 km 3D distance and 109.7 kJ modelled rider energy. Independent visual verification of all PNG contents is still pending.

The `synthetic_*.svg` and `synthetic_*.png` images are **separately generated illustrative previews**, not MATLAB exports. All files here depict a synthetic demonstration rather than the original university group project.

The script is intended to regenerate `matlab_01_3d_route.png` through `matlab_06_power_energy.png`. Actual results can differ if data, settings, or script versions are changed.
