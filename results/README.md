# Figure previews and MATLAB outputs

The three `synthetic_*.svg` preview figures are lightweight charts built from the fictitious GPX data in `../data/synthetic_ride.gpx`. They were **not exported from MATLAB**, and they are not results from the original university group project.

To generate actual MATLAB output figures, run `../run_cycling_demo.m`. The script is designed to save six additional PNG figures here, named `matlab_01_3d_route.png` through `matlab_06_power_energy.png`. These PNGs have **not been verified by a MATLAB run** here.
